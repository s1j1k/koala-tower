# ATC Trainer

Free practice drills for the Airservices Australia ATC selection tests: mental maths, unit conversions and speed/distance/time, with more test-style drills coming.

## Run it
Open `index.html` in any browser. There's no install or build step.

## Build it out
Open this folder in Claude Code. `CLAUDE.md` explains the context, the current features and the roadmap.
